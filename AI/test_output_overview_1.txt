Title: CityComm
Summary: CityComm is a city service platform that connects citizens with city services through an online portal. It uses TypeScript for the backend and React frontend. The platform integrates with Google maps and AI for service categorization. It aims to reduce citizen frustration and improve service delivery.
Roles:
- Backend Developer
- Frontend Developer
- AI Engineer
- Map Engineer
- Citizen Advocate
Features:
- Issue Reporting
- Service Access
- Categorization
- Citizen Feedback
- Pilot Phase
- Full Scale Implementation
- Survey Evaluation
- Citizen Advocacy
Goals:
- Develop issue reporting feature
- Implement service access
- Train AI for categorisation
- Design citizen feedback form
- Launch pilot phase
- Complete full-scale implementation
- Evaluate citizen advocacy
Timeline:
Week 1: Define scope from goals, Design feature architecture
Week 2: Implement core backend flows, Build frontend interfaces
Week 3: Integrate modules and APIs, Validate end-to-end behavior
Week 4: Run QA and bug fixes, Deploy and monitor release
